# Diagnosing Adversarial PACS Image Tampering

This project detects adversarial tampering attacks in PACS chest X-ray images using CNN and Flask.

## Features
- Gaussian Noise Attack
- Blur Attack
- Blackout Attack
- Fake Pneumonia Attack
- FGSM Adversarial Attack
- Grad-CAM Visualization
- Flask Web Application

## Technologies
- Python
- TensorFlow
- OpenCV
- Flask
- CNN
